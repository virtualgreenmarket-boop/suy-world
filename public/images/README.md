# תמונות למערכת הכניסה

## תמונת רקע למסך טעינה

העתק קובץ תמונה לשם `loading-background.jpg` בתיקייה זו כדי להשתמש בתמונת רקע מותאמת אישית למסך הטעינה.

אם הקובץ לא קיים, המסך יציג רקע שחור כברירת מחדל.

### פורמטים נתמכים:
- JPG/JPEG
- PNG
- WebP

### המלצות:
- רזולוציה: 1920x1080 ומעלה
- גודל קובץ: עד 2MB
- תוכן: תמונה מתאימה למשחק או ברנדינג
